# LinkedIn drafts

Ready-to-paste LinkedIn posts generated by `/writeup`, one file per blog post.

Each file contains:
- the post body (hook first, ~800–1500 chars)
- a `First comment:` line — paste the blog link here, NOT in the post body (in-body links suppress reach)
- a posting reminder (best window + reply-in-first-hour)

These are drafts, not part of the built site. Hugo only renders `content/`.
