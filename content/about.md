Hi, I'm Suraj. I've been writing code since 2015 and I'm still a generalist by choice: Java, Ruby, Python, Node, Objective-C, Android, and now whatever an AI agent and I can architect together. I've worked inside scrappy startups and large-scale platforms, sat close enough to product and design to care about the end result, and led a small team of junior developers for a year.

I build fast now by directing AI agents instead of typing every line myself. I own the architecture, the data model, and the judgment calls that matter; the agent does the typing. It's the same skill I used running that team of junior developers: write a clear spec, read every line that comes back, throw out what's wrong, push back when a shortcut isn't worth it. I don't need headcount for that anymore, just an evening free. Membral is the clearest proof: a knowledge graph over 976 of my own AI conversations, 2,082 nodes and 2,107 edges, built solo, with agents doing the implementation while I made the calls on the data model.

Most of what's on this site got built the same way. [See everything I've built →](/projects/)

I also keep building outside work hours: a side-hustle app that runs a small PG rental business, a Chrome extension that let you ask questions about a YouTube video before YouTube shipped the same feature.

I create content on [Instagram](https://www.instagram.com/whimsicallearnings/) and [Youtube](https://youtube.com/@whimsicallearnings?si=2jbHUO5joFHIq2ns), write about the interesting and painful parts of the job [on this blog](/posts/), and when I'm away from a keyboard I'm a husband, a father, an audiobook addict, and a mediocre-but-committed chess player.
